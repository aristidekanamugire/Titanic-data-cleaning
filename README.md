# Titanic-data-cleaning
Pandas-based Titanic dataset cleaning and munging  – handles missing values, feature engineering, and exploratory analysis with visualizations and summaries.

- Implements:
  - Data loading from CSV (Titanic survival data)
  - Inspection: Head, info, describe, missing values
  - Cleaning: Impute/fill NaNs, drop columns, rename
  - Basic EDA: Stats summaries + styled tables
- Dataset: Titanic CSV (891 rows, survival/passenger info)

### Key Results
- Missing values: Age (~20%), Cabin (~77%), Embarked (~0.2%)
- Renamed columns + added 'home' feature
- Styled outputs for easy reading (first 10 rows, summaries)
